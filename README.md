# FNEX CLIENT (Fabric) - Minecraft 26.2 und 26.3

Der GitHub-Build (`.github/workflows/build.yml`) erzeugt fuer beide Versionen je eine `.jar` und eine `.mrpack`:
`fnex-client-26.2-1.0.0.jar` / `fnex-client-26.3-1.0.0.jar` (Artifacts `fnex-client-26.2` und `fnex-client-26.3`).

## Neu
- **Groesse pro HUD-Element:** Einstellung "Size" (0.5x - 3x) in jedem HUD-Modul, oder im HUD Editor
  das Mausrad ueber einem Element drehen.
- **Donut-Cosmetic:** Cosmetics -> "Donut" (rotierender rosa Donut-Ring aus Partikeln um dich herum).

## Installation (Modrinth App)
1. Artifact der gewuenschten Version herunterladen und entpacken.
2. `.mrpack` in die Modrinth App ziehen (Add instance -> Import from file) -> Play.
3. RIGHT SHIFT = FNEX-Menue. Einstellungen liegen in `.minecraft/config/fnex/`.

Benoetigt Java 25 (die Modrinth App besorgt sie normalerweise selbst).
